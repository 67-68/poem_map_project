docker volume ls | grep vscode-server-data
docker volume rm vscode-server-data

# 迁移打包出来的历史文件
cd /Users/lennon/Projects/poem_map_project
docker cp nostalgic_hawking:/home/vscode/Downloads ./local_download_rescue
rsync -av --remove-source-files ./local_download_rescue/ /Users/lennon/Downloads/roocode_history
find ./local_download_rescue/ -depth -type d -empty -delete

*-a 归档模式（保证权限/属性不丢）*
*-v 详细输出（让你看见它没在偷懒*
*--remove-source-files 保证文件成功迁移后，删掉源头文件*
*🚨 极度重要：source 后面的斜杠 / 是灵魂！它代表“迁移文件夹里的内容”，没加这个斜杠就会变成“把整个文件夹作为一个子目录塞进去”。*
*善后：rsync 的 --remove-source-files 只删文件不删空目录。执行下面的命令清理掉源头剩下的空壳：*
