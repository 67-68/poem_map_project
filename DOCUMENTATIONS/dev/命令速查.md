同时focus和normal不同

在 Godot 的 Theme 系统中，主题的传播机制是这样的：
资源继承： 子节点会继承父节点的全局 Theme 资源（那个 .tres 文件）。
变体不继承： 子节点绝对不会继承父节点的 Type Variation 名称！
如果你给 PanelContainer 挂了 NarrativeText 这个变体，引擎在渲染时会去 Theme 里找：“有没有给 PanelContainer 准备的叫 NarrativeText 的 StyleBox？” （显然你没做，所以它什么都不干）。
