# 04 — 事件库案例与维度矩阵

> 本文档汇集了陋室期基于三种旷达状态的具体事件案例，展示了同一情景如何通过状态路由产生完全不同的结算与叙事张力。
>
> 源对话：[`陋室阶段——旷达系统设计.md`](../陋室阶段——旷达系统设计.md)

---

## 1. 事件库维度设计综述

一套基于"三种旷达状态"的事件路由矩阵，一旦想清楚了，扩展起来像流水线一样顺滑。不需要堆砌毫无意义的文本，只需在盛唐的社会结构里寻找那些"测试底线的极端场景"。

### 核心设计模式：情绪守卫分支模式

每个事件遵循固定的 3-option 范式：

| 位置 | 条件 | 特性 |
|------|------|------|
| **Option A** | Requires: 高旷达 (狂客) | 正面/理想主义/有风骨的回应 |
| **Option B** | Requires: 中旷达 (逢迎) | 中庸/明哲保身的回应 |
| **Option C** | Requires: 低旷达 (钻营) | 功利/没有底线的回应，收益最高但代价最大 |

## 2. Case 1：富商的墓志铭（变现才华的底线测试）

**触发节点：** 【驻留·场景化行动】→ 逛东西两市，此时玩家处于严重资金短缺状态。

**情景描述：** 一个暴发户商人（无政治背景，单纯有钱）拦住你。他知道你是那个"写诗有点名气但穷得叮当响的杜二"，想出重金让你给他刚过世的文盲父亲写一篇极尽吹捧的墓志铭。

### 选项分支

#### 选项 A：[严词拒绝] (Requires: 高旷达)

| 字段 | 内容 |
|------|------|
| **文本** | "杜某的笔，只写山河社稷，不写铜臭之物！" |
| **结算算子** | 获得 `[狂客的名望]`（穷且益坚），可能引发路人围观叫好。但你错过了一大笔钱，下半旬直接面临挨饿判定 |
| **叙事价值** | 坚守底线，用风骨换生存压力 |

#### 选项 B：[捏鼻收钱，敷衍了事] (Requires: 中旷达)

| 字段 | 内容 |
|------|------|
| **文本** | "罢了，一文钱难倒英雄汉……" |
| **结算算子** | 写了一篇辞藻华丽但毫无灵魂的套路文章。获得足够撑过一旬的 `[生存资源]`，但增加一层隐性的 `[自我厌恶]` |
| **叙事价值** | 妥协但痛苦，文人的日常屈辱 |

#### 选项 C：[主动加戏，攀附名门] (Requires: 低旷达 / 钻营)

| 字段 | 内容 |
|------|------|
| **文本** | "令尊相貌惊奇，想必祖上是陇西李氏旁支吧？小人可在铭文中为您润色一二。" |
| **结算算子** | 不仅写了，还主动帮暴发户伪造了高贵的门第。获得翻倍的巨额 `[生存资源]`（一夜暴富）。但在清流圈子里传开，诗歌库被深度污染，**永久失去生成"风骨类"绝句的概率** 💀 |
| **叙事价值** | 用灵魂换金钱，不可逆的污染 |

## 3. Case 2：清流朋友的政治危机（连坐与自保）

**触发节点：** 【交游】→ 传闻事件（不可控外部触发）。

**情景描述：** 至交好友郑虔（纯正的清流、穷鬼老实人）因为私下抱怨李林甫，被御史台盯上了，马上就要被贬官或下狱。浊流的眼线（某个小官）故意在酒局上问你："杜参军，听说你和郑虔走得很近啊？"

### 选项分支

#### 选项 A：[拍案而起，怒斥权臣] (Requires: 高旷达)

| 字段 | 内容 |
|------|------|
| **文本** | "郑公乃当世大儒，尔等鹰犬也配议论？！" |
| **结算算子** | 郑虔好感度拉满，李白等人引为知己。但你直接获得 `[右相府黑名单]` Trait，长安城内所有浊流相关的资源接口全部返回 **403 错误**，并概率触发被地痞殴打事件 |
| **叙事价值** | 义气冲天，但社会资源断供 |

#### 选项 B：[顾左右而言他] (Requires: 中旷达)

| 字段 | 内容 |
|------|------|
| **文本** | "杜某近日只顾饮酒作诗，对朝堂之事一概不知。" |
| **结算算子** | 明哲保身。浊流官员冷笑一声放过你。逃过一劫，但事后去给郑虔送行时，自动触发一段极度压抑的内心独白（无数值惩罚，纯情绪压迫） |
| **叙事价值** | 安全的苟且，但良心的鞭笞比数值惩罚更痛 |

#### 选项 C：[顺水推舟，撇清关系] (Requires: 低旷达 / 钻营)

| 字段 | 内容 |
|------|------|
| **文本** | "下官确与他喝过几次酒，早察觉此人言语狂妄，正欲向大人举报呢。" |
| **结算算子** | 进行了一次完美的被动钻营。踩着朋友的尸体向浊流递了投名状。郑虔流放，而你获得浊流赏赐的 `[长安闲职]`（每月固定产出资金），并正式解锁右相府的拜谒权限 |
| **叙事价值** | 用朋友换饭碗，道德深渊的第一步 |

## 4. 历史暗线：系统真实性的底层映射

### 4.1 李林甫的防火墙（官方 API 被强行阻断）

公元 747 年，李林甫搞出"野无遗贤"闹剧。唐朝官方上升通道（科举 API）全线返回 `403 Forbidden`。杜甫、高适这帮人全部被卡在防火墙外。

**行为动机：** 既然官方接口断了，想要入仕，杜甫唯一能走的是"拜谒"（权贵内推机制）。为了拿到推荐信 Trait，他不得不去干屈辱的事。

### 4.2 残杯冷炙：真实的生存结算

杜甫在《奉赠韦左丞丈二十二韵》里写了：

> **"朝扣富儿门，暮随肥马尘。残杯与冷炙，到处潜悲辛。"**

- **解读：** 早上跑去敲富贵人家的大门求见，傍晚跟在达官贵人的肥马扬起的灰尘后面吃尾气。换来的是"残杯冷炙"（别人吃剩下的酒肉）。
- **系统映射：** 杜甫这是在拿 `[才华]` 和 `[尊严]` 换取最低限度的 `[生存资源]`，全过程隐忍。在权贵眼里，就是一个写诗好听的乞丐。

### 4.3 边缘实体的互相取暖（郑虔与李白）

- **结构与粒度：** 杜甫和郑虔关系好，因为郑虔在历史上是个"三绝"学霸但穷得令人发指。杜甫给他写诗："才名四十年，坐客寒无毡。"
- **底层逻辑：** 杜甫、郑虔、李白的感情真挚，正是因为他们在"盛唐政治核心网络"中统统是孤立节点。连网都连不上。两个被时代抛弃的、吃不饱饭的穷光蛋，在长安雪夜里喝着劣质酒——这种抱团取暖的底层链接，是对权贵网络最彻底的嘲讽。

### 4.4 三大礼赋的徒劳（751年）

玄宗看到《三大礼赋》很高兴，让杜甫去考试，考完之后……**把他扔进了待命池（集贤院待制），然后就忘了。**

他又接着在长安当了四五年的小丑，直到安史之乱爆发。对应系统设计：消耗巨额资源后 MONEY 收益为 0，只能拿到虚名。

## 5. 兜底机制：高旷达玩家的生存保障

如果玩家为了体验"真正的李杜精神"，死磕【高旷达】选项，导致生存资源疯狂流失，需要兜底机制防止前 15 分钟就因为没钱 Game Over：

### 方案

1. **强制生病事件：** 当生存资源低于阈值时，触发杜甫卧病在床事件。王维/郑虔前来探望，赠送药材和粮食（低保生存资源）。
2. **历史救济事件：** 触发"平民施舍"的随机事件——穷苦百姓看到杜甫饿倒在路边，反而施舍他（体现底层互助）。
3. **强制负债机制：** 允许杜甫欠房租，但触发房东催租的压力事件，直至生存资源恢复后自动扣款。

## 6. "小丑"与"知音"不冲突的底层逻辑

### 历史/政治沙盘推演

为什么"为了生存去当小丑"和"李白他们的真感情"不冲突？

**社交网络严格拆分为两个相互隔离的圈层：**

| 圈层 | 实体 | 杜甫的角色 | 产出 |
|------|------|-----------|------|
| **政治权力实体** | 李林甫、王公贵族、高官 | 宠物/清客，写诗奉承的小丑 | 生存资源（赏钱、残羹冷炙） |
| **文化边缘实体** | 李白、高适、郑虔、杜甫 | 政治上都是 Loser，抱团取暖 | 情绪价值（诗歌、精神状态恢复） |

**两个圈层没有任何资源交换通道：** 去当小丑才能拿到生存资源；去找李白只能拿到情绪价值，**绝对不能产出金钱**。

### 为什么"小丑"和"知音"可以共存？

因为李白他们在权力面前一样是小丑。就像现代大厂底层外包员工：白天都在老板面前当孙子，承受各种奇葩要求；晚上在大排档喝酒骂娘——这种感情能不真挚吗？

**机制隔离就是对玩家最好的叙事：**
- 想活下去，就必须咽下屈辱
- 想去大排档找兄弟寻求真感情，就得做好下个月交不起房租的准备
- 每次去找李白喝酒，都是一次顶着破产风险的"浪漫抉择"
