# 06 — 意象与情绪获取方式参考

> 本文档定义陋室期意象（Imagery）与情绪（Emotion）的**获取方式类型体系**。每种类型从机制本质、与事件库的关系、玩家代理权高低来描述。
>
> 本文档是纯机制参考。各事件库具体使用哪些方式，见 [`05-事件库与意象情绪获取映射.md`](05-事件库与意象情绪获取映射.md)。

---

## 总览

意象/情绪的获取方式共分为 **六大类型**。区分这些类型的核心维度是：**玩家主动程度、是否需要情绪阈值守卫、是否涉及 NPC/社会后果、意象产出的确定性**。

| 方式 | 名称 | 玩家主动 | 产出意象 | 关键特征 |
|------|------|:---:|:---:|------|
| **A** | 情绪守卫分支 | 半主动 | ✅ | 阈值守卫选项可见性 |
| **B** | 纯场景渲染 | 被动 | ❌ | 仅叙事+资源结算 |
| **C** | 打分选择器 | 半主动 | ✅ | 白名单池×情绪亲缘度 |
| **D** | 主动兑换 | 主动 | ✅ | 消耗资源换产出 |
| **E** | 选择残渣 | 间接 | ✅/❌ | 行为副作用 |
| **F** | 环境渲染 | 被动 | ❌ | 季节/地点/时间注入 |

---

## 方式 A：情绪守卫分支 (Emotion-Guarded Branch)

### 机制

用 `requirements` 守卫选项可见性。每个事件固定 3 个分支：

```
事件触发 → 展示选项
    ├── 分支 A: EMOTION_A ≥ 阈值 → 代价 + 意象
    ├── 分支 B: EMOTION_B ≥ 阈值 → 不同代价 + 不同意象
    └── 分支 C: 无条件兜底        → 无意象（平庸惩罚）
```

### 设计原则

- 玩家没积累对应情绪 → 连选项都看不到（灰色锁定 = 叙事）
- 必须至少有一个无条件兜底选项，防止死锁
- 仅关键节点使用，日常事件不用

### 情绪对立配对表

| ID | 名称 | 分支 A 情绪 | 分支 B 情绪 |
|----|------|-----------|-----------|
| `pair_rebellion` | 反抗 vs 超脱 | ARROGANCE（狂傲） | TRANQUILITY（旷达） |
| `pair_despair` | 毁灭 vs 自毁 | ANGER（愤怒） | SORROW（悲伤） |
| `pair_survival` | 功利 vs 麻木 | AMBITION（野心） | FATIGUE（疲惫） |

---

## 方式 B：纯场景渲染 (Scene-Only Rendering)

### 机制

事件仅由场景驱动，**不产出任何意象**。场景负责叙事氛围（白描 + 环境细节），结算只给资源或情绪变更。

### 适用场景

公域偶遇、系统级强中断、过渡性叙事。凡是叙事本身即是目的、不需要意象奖励的事件都用此方式。

---

## 方式 C：打分选择器 (Scoring Selector)

### 机制

场景圈定合法意象白名单（3-5 个）→ 每个意象有情绪亲缘度 (0-100) → 按目标情绪打分 → 最高分 ≥ 阈值则掉落，否则丢弃。

```
白名单池(场景决定)
    → 亲缘度(预配置)
        → 目标情绪 × 亲缘度 = 得分
            → 最高得分 ≥ 30 → 掉落
            → 最高得分 < 30 → 丢弃
```

### 与方式 A 的区别

| | 方式 A（情绪守卫） | 方式 C（打分选择器） |
|------|------|------|
| 守卫机制 | 玩家情绪阈值 | 无守卫，纯算法匹配 |
| 意象掉落 | 确定性（守卫通过必掉） | 概率性（分数不够不掉） |
| 玩家代理权 | 高（平时攒情绪） | 低（系统自动计算） |
| 白名单 | 无（按 emotion tag 随机） | 有（场景圈定） |

---

## 方式 D：主动兑换 (Active Exchange)

### 机制

玩家**主动消耗资源**（金钱/体力/时间），向系统兑换意象产出或情绪清理。这是唯一玩家具有完全主动权的方式。

### 结算模式

兑换时可能伴随以下情绪注入模式：

| 模式 | 描述 | 示例 |
|------|------|------|
| **单点刺穿** | 只加 1 种情绪，中高数值 | `prop_add(name=SORROW; val=15)` |
| **零和博弈** | 情绪 A +20，对立情绪 B -20 | `prop_add(name=ARROGANCE; val=20)` + `prop_add(name=TRANQUILITY; val=-20)` |
| **催化剂** | 1 种情绪 + AMBITION | `prop_add(name=SORROW; val=10)` + `prop_add(name=AMBITION; val=10)` |

### 与方式 E 的区别

| | 方式 D（主动兑换） | 方式 E（选择残渣） |
|------|------|------|
| 玩家意图 | 明确要结果 | 无意间附带 |
| 投入-产出链路 | 显式 | 隐式 |
| 典型例子 | 花钱买醉消解悲伤 | 选了某个行为后被塞了负面情绪 |

---

## 方式 E：选择残渣 (Choice Residue)

### 机制

叙事选项的**副作用**——玩家选择了某个行为后，系统附带结算情绪或意象。玩家不是主动购买这个结果，而是行为本身带来的心理后果。

### 核心特征

- 产出方向通常与行为意图相反（如：拜谒权贵拿到钱，但附带悲伤和自我厌恶）
- 是叙事驱动的方式，不依赖算法或配置表
- 情绪方向由事件设计者提前决定，非随机

---

## 方式 F：环境渲染 (Environmental Injection)

### 机制

季节/地点/时间**被动注入**情绪，不直接产出意象。是情绪的底层「蓄水池」——为方式 A 和方式 C 提供情绪弹药。

### 三种通道

| 通道 | 触发方式 | 示例 |
|------|---------|------|
| **季节** | 每旬自动结算 | 秋季每旬 `SORROW +2` |
| **地点** | 进入特定区域 | 贫民窟 → `SORROW +5` |
| **时间** | 特定时辰 | 深夜 → `FATIGUE +3` |

### 关键约束

- 不直接产出意象
- 有叠加阈值保护：连续多旬不消解自动注入的情绪 → 达到阈值后触发大病事件
- 是方式 D（主动兑换）的反向——方式 F 是被动积累，方式 D 是主动消除

---

## 方式互斥与组合规则

| 规则 | 说明 |
|------|------|
| A 与 C 互斥 | 同一事件不能既用情绪守卫又用打分选择器 |
| B 可与 E 叠加 | 纯场景渲染后附加选择残渣 |
| D 是 C 的前置 | 登高中先消耗体力（D）再打分（C） |
| F 是 A+C 的前置 | 环境渲染积累情绪 → 情绪守卫/打分选择器才能触发 |
