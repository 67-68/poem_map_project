# 02 — 路线设计与状态转移

> 本文档定义了陋室期的三条核心行动路线、旷达状态的非对称转移机制（迟滞效应），以及与清流/浊流党争线的兼容方案。
>
> 源对话：[`陋室阶段——旷达系统设计.md`](../陋室阶段——旷达系统设计.md)

---

## 1. 三条核心路线 Trade-off

在盛唐长安的"陋室期"，玩家面对三个互相抢占资源的行动路线。核心矛盾在于：**你不能只要尊严，也不能只要生存。**

### 路线 A：极致的【拜谒】（向权力下跪）

| 维度 | 描述 |
|------|------|
| **行动本质** | 把你的才华当成 API 接口，免费给达官贵人调用（写献媚诗、候门、陪笑） |
| **收益 (Yield)** | 极高的 `[生存资源]`（赏钱、吃饱的饭）、微乎其微的 `[引荐信/入仕概率]` |
| **代价 (Cost)** | 断崖式暴跌的 `[尊严/情绪]`，在上层社交网络被打上 `[清客/小丑]` 的 Trait |
| **极限状态 (Min/Maxing)** | 若每旬无脑点拜谒，会成为长安城活得最滋润的"宠物"。绝不破产，甚至能混个小吏。但诗歌库里全是垃圾奉承诗，李白高适看不起，历史也会抹除。"你活下来了，但'杜甫'这个概念死档了 💀。" |

### 路线 B：极致的【交游】（在边缘圈层抱团取暖）

| 维度 | 描述 |
|------|------|
| **行动本质** | 去和李白、高适、郑虔这些同样的"政治 Loser"喝酒唱和 |
| **收益 (Yield)** | 极高的 `[诗歌灵感/情绪价值]`，获得传世名作碎片，拿到 `[饮中散仙]` 等文化界高级 Trait |
| **代价 (Cost)** | 极速消耗 `[生存资源]`。李白他们也很穷，蹭饭最多获得极低保底生存值（饿不死但交不起房租），`[政治野心]` 停滞 |
| **极限状态 (Min/Maxing)** | 成为大唐最浪漫的狂人，写出无数千古绝唱。但突然某天系统结算生存费用，因长期没去当小丑赚钱，直接破产。"带着满脑子的绝句，被房东扫地出门，冻死在街头，打出【饿死长安】的 Game Over 😭。" |

### 路线 C：极致的【闭门/决议】（憋大招：三大礼赋）

| 维度 | 描述 |
|------|------|
| **行动本质** | 拒绝无效社交，也不去当小丑，把自己关在漏雨的破屋里做"大型项目"（写赋求皇上） |
| **收益 (Yield)** | 项目完成后，一次性爆发巨额的 `[名声]` 和 `[直达天听的决议事件]` |
| **代价 (Cost)** | 长达数个旬/月的读条期间，`[生存资源]` 和 `[健康/精神]` 被疯狂抽干（Money 收益为 0） |
| **极限状态 (Min/Maxing)** | 像在没有外部投资的情况下强行搞重资产研发。若前期没攒够钱或没去求权贵打底，进度条卡在 99% 时就会因健康归零或彻底破产而猝死 😨。 |

### 系统的残酷美学

为了憋出三大礼赋（路线 C），或者为了能和李白继续喝酒（路线 B），玩家**必须**捏着鼻子去权贵门前当小丑（路线 A）赚取缓冲资金。

**真正的 Trade-off：用屈辱换取浪漫，用妥协供养野心。**

## 2. 状态转移：迟滞效应 (Hysteresis)

传统 RPG 的"杀人放火后刷道德值"是反模式。如果堕落和洗白是对称的，玩家会把系统当成"反复横跳的资源提款机"。为此引入物理学和控制论中的 **迟滞效应 (Hysteresis)**——堕落是重力，觉悟需要逃逸速度。

### 2.1 向下兼容：温水煮青蛙 (Mid → Low)

从【中旷达】掉入【低旷达】绝对不能是一次打击，必须是一场缓慢的"慢性中毒"。

**数据流转：**
1. 玩家在【诗作】系统中，为迎合权贵赚取打赏，反复选择 `[华丽]`, `[颂圣]`, `[肥马]`, `[金樽]` 等意象
2. 系统后台维护一个 `dirty_imagery_count`，当计数器超过阈值时，说明杜甫已在潜意识里习惯了当权贵的玩物
3. **网关拦截：** 在【驻留】或【拜谒】时，必然触发"权贵让你干脏活"的决议事件
4. **状态跃迁：** 没有任何心理挣扎的描写，因为前面的写诗过程已把底线磨平。点下"接受"，状态无缝滑落至 `[低旷达/钻营]`

**这是一种极其丝滑、甚至让玩家觉得"理所当然"的堕落。**

### 2.2 向上逆行：断尾求生的系统级灾难 (Low → High)

处于 `[低旷达]` 的玩家想要回到 `[高旷达/狂客]`，**绝对不能通过"多写几首清高诗"来洗白！** 意象计数在向上跃迁时是锁死的（此时写的清高诗在别人眼里只是虚伪的作秀）。

必须触发极其罕见的 **[破釜沉舟 (The Blood Sacrifice)]** 级别事件：

| 步骤 | 内容 |
|------|------|
| **触发条件** | 面临"极高道德危机"时（如郑虔被捕，或看到路边冻死骨），强行选择被标红、带骷髅头警告的选项——**公然反叛** |
| **结算 1：资源清零** | 之前当狗攒下的所有 `MONEY` 被权贵以"贪墨/欺诈"罪名全部抄家没收 |
| **结算 2：人脉熔断** | 失去所有权贵侧关系网，清流那边也将信将疑（社会关系清零） |
| **结算 3：物理惩罚** | 被权贵家丁暴打扔出长安城门，扣除 80% 健康值 |
| **最终跃迁** | 一无所有、濒临死亡地躺在城外雪地里时，系统才将状态切回 `[高旷达]`，塞入极度悲壮的诗歌意象 |

> 这种不对称设计完美封死了玩家 Min/Max 功利化刷状态的可能。当他们看到向上跃迁的代价是"删档级别的资源清零"时，在前期决定要不要写那首"颂圣诗"时，手就会开始发抖了。

## 3. IAM vs JWT：旷达状态与社交标签的正交解耦

### 3.1 架构定义

| 概念 | 对应 | 本质 | 作用域 |
|------|------|------|--------|
| **旷达状态** | IAM Role（内部权限） | 玩家"愿意干什么 / 能干什么" | 控制 Action Gateway（行动按钮的禁用/启用） |
| **社交标签** | JWT Payload / DB Record（外部资产） | 别人眼中的"客观社会印记" | 控制 NPC 对玩家的态度和触发的事件 |

**绝对不能合并。** 把"用户是否登录了系统（State）"和"用户的账户余额是多少（Asset）"混存在一个变量里，代码写出来是要被钉在历史耻辱柱上的。

### 3.2 错位产生的叙事张力

这两个正交系统通过组合涌现出极致的悲剧美学：

#### Case A：高旷达 + `[权贵圈的笑柄]`

玩家前期为活命（中低旷达）给权贵当狗，拿到 `[笑柄/清客]` 标签。后来触发破釜沉舟事件跃迁回 `[高旷达]`，重新做人。

**化学反应：** 玩家现在内心骄傲，面对权贵邀约只会"严词拒绝"。但权贵眼里这丫就是个曾经摇尾巴的狗，会触发侮辱性随机事件："哟，杜二，听说你最近长脾气了？以前舔盘子的时候可不是这样的啊。"

**玩家体验：** 历史遗留问题让你哪怕洗心革面，也要承受过去的代价。

#### Case B：低旷达 + `[落魄文人的知音]`

玩家内心烂透了（低旷达），但极其聪明地装可怜、写好诗骗取清流真挚感情，拿到 `[知音]` 标签。

**化学反应：** 系统校验权限是 `[低旷达]`，所以可接脏活。但系统同时校验有 `[知音]` 标签，李林甫管家找上门："听说你和那帮清流关系很好？去，帮我套套他们的话。"

**玩家体验：** 极致的赛博变态——看着李白把你当真兄弟（因为标签），但反手就把他卖了（因为状态）。

### 3.3 代码级协议

```
if 涉及"杜甫主动做出的主观选择":
    判断条件只查「旷达状态」
if 涉及"别人主动找上门的事件 / NPC 的对话态度":
    判断条件只查「社交标签」
```

## 4. 党争线兼容方案

原有的"拜谒清流→浊流敌视"/"拜谒浊流→清流敌视"设计，在三种旷达状态下不仅兼容，而且能做得更深刻。

### 4.1 架构纠错：党派不是"门派"，是"投资与利用机制"

- **旧认知：** 拜谒 = 加入门派
- **真实沙盘：** 拜谒 = 提交简历，党争 = 权贵在做风投

### 4.2 状态机路由：钻营 → 党争线

#### 第一阶段：隐蔽的门票（投名状事件）

当玩家旷达状态掉入 `[钻营]` 时，在【交游】或【拜谒】路线中解锁隐蔽阴暗事件池。

- **触发场景：** 在王维宴席上做小丑，偶然听到清流讽刺李林甫的"反诗"。
- **选项分支：**
  - `[狂客/逢迎]`：跟着笑或装听不见（无事发生）
  - `[钻营]`：解锁红色警告选项 **暗中抄录，递交右相府** 😨

#### 第二阶段：破而后立的代价

- 失去所有清流朋友好感，获得 `[清流公敌]` 负面标签
- 获得巨额赏金（解除生存危机）
- 获得 `[右相府·鹰犬 (外围)]` 隐藏 Trait

#### 第三阶段：路线锁定

一旦挂了 `[右相府·鹰犬]` Trait：
- **交游**面板对所有清流关闭（飘灰）
- **奉诏/拜谒**面板刷新全新"浊流专属任务"
- 史书文名彻底臭了，诗篇变成政治垃圾

### 4.3 为什么这样设计比"接请帖"好？

1. **不破坏战争迷雾：** 没有直接见最终大 Boss，是从底层逻辑（告密/干脏活）慢慢渗透进权力 NPC
2. **约束的悖论：** 玩家不是在 UI 上轻松点"加入浊流"，而是在"下个月就要饿死"的极端生存压力下，咬着牙点下告密选项
3. **极简工程实现：** 不需要写庞大前置剧情，只在已有事件加 `if trait == '钻营'` 的选项并 `add_trait('右相府外围')`，整个后期事件树自动导流

## 5. 清流钻营路线：流量寄生

### 5.1 路线定调

严格区分 **状态（State）** 和 **决议（Decision）**：
- `[钻营]` 只是一个**失去道德包袱的马基雅维利状态**，不决定投靠谁，只决定**行事底线**
- 在这个状态下，既可以给浊流当狗，也可以把清流当成"流量提款机"

### 5.2 渐进式事件链

#### 阶段一：启动期 — 笨拙的作秀 (Performative Acting)

刚进入 `[钻营]` 的杜甫并不擅长操纵清流。他参加清流诗会时，写出来的诗生硬地模仿李白的狂傲，但由于内心已不再纯粹，被王维一眼看穿："子美，你这首…… 少了点魂。"

- **结算：** 名声增长极慢，且每旬触发 `[自我厌恶]` 检定。

#### 阶段二：发展期 — 流量寄生 (Traffic Leeching)

此阶段的杜甫已掌握了"怎么在清流圈里包装自己"。他学会了一个极其卑鄙的操作：**有选择地在公开场合泄露自己"被权贵欺辱"的细节，利用清流的同情心来博取流量。**

- **结算：** 大幅获取 `[民间声望]`，但你向权贵圈子散布了"自己深受其害"的假象。权贵们看着你的表演，冷笑着在你的档案上记了一笔——`[两面三刀]` Trait 计数 +1。

#### 阶段三：成型期 — 道德绑架 (Moral Hijacking)

最高阶的钻营形态。你不再是去"交朋友"，你变成了清流圈的精神领袖。你去替郑虔出头，不是为了正义，是因为你判定"只要保下郑虔，你的文坛声望会暴增"。

- **结算：** 你获得了清流圈的绝对支持，但你已经无法再写出一句真诚的诗。你的诗歌引擎里，所有带 `[纯真]` Tag 的意象被彻底锁定。

### 5.3 虚伪的代价

- 你的名声变成了纯粹的货币，失去了任何情感绑定的可能性
- 后期如果要追求"真结局"，你需要面对清流朋友被清算时，你是抛弃他们还是自我牺牲的终极拷问
- 游戏结算时，结算面板里会写一行："你成为了长安最耀眼的明星，你的诗被刻在石碑上，但你自己知道…… 那是尸体的防腐剂。" 💀
