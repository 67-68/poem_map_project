## 架构速览

### 核心概念

```
旷达系统 (Kuàngdá System)
├── 三个离散状态（取代 0-100 数值刻度尺）
│   ├── 狂客 (高旷达) — 内心骄傲，视官员为普通人
│   ├── 逢迎 (中旷达) — 客气但痛苦的小丑状态
│   └── 钻营 (低旷达) — 失去道德底线的阴谋家
├── 六大行动网关 (API Endpoints)
│   ├── 交游 — 清流圈人设维护
│   ├── 拜谒 — 权贵圈屈辱换电
│   ├── 坊市 — 公域生存盲盒
│   ├── 奉召 — 系统级强中断
│   ├── 独酌 — 内部状态 GC
│   └── 登高 — 视野跃迁 + 意象锻造炉
├── 非对称状态转移 (迟滞效应)
│   ├── 向下: 意象计数缓慢中毒 (dirty_imagery_count)
│   └── 向上: 破釜沉舟级灾难 (资源清零 + 人脉熔断 + 物理惩罚)
└── 正交解耦
    ├── 旷达状态 = IAM Role (内部权限)
    └── 社交标签 = JWT Payload (外部资产)
```

### 关键事件

```
三大礼赋 → 未站队玩家的"杀猪盘"Pipeline
高适离开 → 按状态分发三种 Debuff (道心破碎/急不可耐/变本加厉)
被动钻营 → 捡拾李白废弃资源的"残羹冷炙"路由
情绪守卫 → 3-option 固定事件范式 (高旷达/中旷达/低旷达)
```

## 设计原则

1. **契约即自由：** 严格的类型系统、明确的接口边界、固定的 Action Gateway 路由规则，反而赋予玩家真正的策略深度
2. **迟滞效应：** 堕落是重力（温水煮青蛙），觉悟需要逃逸速度（删档级代价），防止玩家 Min/Max 反复横跳
3. **正交解耦：** 内心状态（IAM）与社会标签（JWT）各自独立，通过错位产生叙事张力
4. **机制隔离即叙事：** 拜谒权贵产出生存资源，交游清流产出情绪价值，两个通道严格隔离，玩家每一次选择都是"浪漫抉择"
