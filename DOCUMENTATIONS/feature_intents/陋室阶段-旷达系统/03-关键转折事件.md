# 03 — 关键转折事件

> 本文档定义了陋室期三个最关键的转折事件：三大礼赋的"杀猪盘"机制、高适离开的全局 Debuff 系统，以及被动钻营/李白废弃请帖的事件路由。
>
> 源对话：[`陋室阶段——旷达系统设计.md`](../陋室阶段——旷达系统设计.md)

## 1. 三大礼赋的"杀猪盘" (Sunk Cost Pipeline)

### 1.1 历史背景

751 年，玄宗举行三大盛典（封禅、祭祀等）。杜甫历史上献上《三大礼赋》，这是他对"拜谒"体系失灵后的一次**侧信道攻击 (Side-Channel Attack)**——试图越过李林甫的网关直接修改底层数据库的疯狂举动。

### 1.2 触发条件

**方案 B（已选中）：状态与时代的复合约束 (State-Driven Event)**

```
Date >= 749 && Date <= 753
&& (State == '逢迎' || State == '钻营')
&& 绝望度 > 阈值
&& 未站队（无清流/浊流 Faction Tag）
```

**三大礼赋本质上是一个针对"未站队散户玩家"的陷阱，只对中、低旷达开放。**

### 1.3 多阶段决策 Pipeline（杀猪盘）

#### 阶段 1：免费钩子 (Free Hook) — "你听说……"

在【坊市】或【交游】中，你听说今年朝廷要大办祭祀。这是一个完全免费的信息，没有 Require 条件。

- **玩家心理：** 获得一个情报，觉得是个机会。没有任何投入，也不警觉。

#### 阶段 2：供应商锁定 (Vendor Lock-in) — "你写了一篇……"

在【决议】面板里，多出了一个选项 **起草《三大礼赋》之一**。

- **时间消耗：** 消耗 2 旬的时间（无法进行拜谒/交游等行动）。
- **早期收益：** 你获得了一点点名声和旁人的夸奖："杜兄好文采！"
- **隐藏结算：** 系统在你的存档里悄悄增加了一个 `[已投入: 1/3]` 的计数器。同时，**你的社交圈开始衰减**——由于你没去拜谒，权贵那边的门路开始生锈；由于你没去交游，清流朋友觉得你最近"有点傲慢"。

#### 阶段 3：沉没成本陷阱 (Sunk Cost Trap) — "你已经写了两篇……"

时间来到 751 年底，你已经投入了 4 旬时间去写赋。

- **强制选项：** 玩家此时获得一个极其具有诱惑力的选项——**你已经完成两篇了，只剩最后一篇，为什么要放弃？**
- **痛苦升级：** 当你点下"继续"时，系统提示：
  > "为了准备献赋，你已变卖了最后一件御寒的冬衣。"
- **结算：** 玩家从 `[逢迎]` 被打入 `[钻营]`（声望剧烈下降）。玩家名满天下，但**穷得连下个月的房租都交不起**。

#### 阶段 4：结算 — "天子看到了你的赋！"

- **结果：** 玄宗很高兴，让杜甫去考试。考完之后……**把他扔进了待命池（集贤院待制），然后就忘了**。
- **实际收益：** `MONEY` 收益为 **0**。只获得了一个虚名 `[待制集贤院]` Trait。
- **讽刺结算：** 你将接着在长安当四五年的小丑，直到安史之乱爆发。

> **架构上的意义：** 这条管线是设计给"不愿彻底站队"的中立玩家的惩罚机制。如果你既不想给李林甫当狗（浊流线），又不想骗清流的流量（清流·钻营线），系统就给你一个"看起来像是主线"的选项，让你在"宏大但无用的项目"中消耗掉所有资源和时间。

## 2. 高适离开：全局 Debuff (Poison Pill)

### 2.1 历史暗线

高适离开长安是陋室期的转折点。高适是杜甫在长安最亲密的同侪之一，他的离开击碎了"底层互慰"的防火墙。此前杜甫还能在清流圈抱团取暖，现在最能理解他处境的人走了，孤独和生存压力同时爆发。

### 2.2 架构设计：毒药补丁 (Poison Pill)

不要去做简单的状态降级。核心事件应作为一个"毒药补丁 (Poison Pill)"打入玩家的事件池，**污染玩家原本最擅长、最依赖的资源获取路线**，逼着他们去做出改变。

这像是系统架构里强行把旧版 API Deprecate（废弃），你在调用就会狂报 Warning，直到你切换到新的悲惨线路上。

### 2.3 按旷达状态的 Debuff 分发

#### 1) 如果玩家处于 [狂客] (高旷达)

- **Debuff: `[道心破碎]`**
- **表现：** 你以前登高能获得"天人合一"的强力 GC（垃圾回收/情绪清理）。但现在站在山顶，看着远去的马车，一股巨大的虚无感击穿了你——"我在这里跟天地共鸣有什么用？我的兄弟去边塞求功名了，我还在长安写山水诗？"
- **效果：** 【登高】行动的 GC 效率下降 50%，产出绝句的概率降低。

#### 2) 如果玩家处于 [逢迎] (中旷达 — 小丑状态)

- **Debuff: `[急不可耐]`**
- **表现：** 你以前当小丑还能自嘲："李林富赏的这碗饭，真香。"但现在高适的成功刺激了你，你开始焦虑。
- **效果：** 【拜谒】时，有概率触发"自尊心爆发"导致白跑一趟（收益归零）。玩家被迫在拜谒中获得更少的收益，逼迫他们思考"是不是该换个活法"。

#### 3) 如果玩家处于 [钻营] (低旷达 — 阴谋家)

- **Debuff: `[变本加厉]`**
- **表现：** 高适的成功让你觉得"在这个时代讲良心果然没用"。你更加疯狂地在权贵面前献媚。
- **效果：** 【拜谒】触发极端事件："为了获取某位王爷的赏识，你需要献祭一位清流朋友的黑材料。" 玩家面临终极道德崩塌的抉择。

### 2.4 引导至三大礼赋

高适离开直接引爆了杜甫的同侪压力与野心。作为"陋室期"大高潮的闭环，这个 Debuff 会极其自然且带有强迫性地将玩家引导向【决议：献上三大礼赋】——那条九死一生、几乎抽干所有资源的孤注一掷之路。

## 3. 被动钻营：李白废弃请帖的路由分发

### 3.1 系统美学：不写新代码，只做状态拦截

在设计里，不需要写一套复杂的"黑化进度条"。只需要把"别人不要的机会/别人丢掉的残羹冷炙"作为事件库的核心输入流。

- **高旷达玩家：** 这游戏是个浪漫的诗歌模拟器
- **低旷达玩家：** 每天在捡李白、高适他们不要的政治垃圾，看着飙升的金钱和跌入谷底的尊严，感受极致的电子窝囊废体验

### 3.2 具体案例：李白废弃请帖

**场景：** 李白最近被赐金放还，心情极度恶劣。他收到了某个富商的宴请请帖，但李白不想去。他醉醺醺地找到杜甫："子美，你替我去吧，随便写两首诗应付一下。"

#### 不同旷达状态的路由：

| 状态 | 玩家理解 | 事件名称 | 结算 |
|------|---------|---------|------|
| **狂客** (高旷达) | 太白兄如此看得起我，这是替兄分忧的机会 | 【替兄赴约的义气】 | 获得清流圈的义气名声；你写了两首豪迈诗，富商不敢怠慢 |
| **逢迎** (中旷达) | 这是个不错的社交场合 | 【勉为其难的社交】 | 你去了，吃了顿饭，写了首中规中矩的诗。富商觉得"杜甫这人文采还行，但不如李白有意思" |
| **钻营** (低旷达) | 草…… 这是天上掉下来的流量啊！李白的残羹冷炙都够我吃一辈子了 | 【捡漏的盛宴】 | 你在宴席上极其卖力（甚至有点卑微），拿走了李白不要的出场费。在权贵眼中，你成了"那个蹭李白热度的 loser" 😭 |

### 3.3 架构意义

不需要写新事件流程。只需要状态机拦截同一个事件入口，根据旷达状态路由到完全不同的分支和结算。**不写新代码，只做状态拦截。**

## 4. 系统落地设计

### 4.1 情绪守卫分支模式 (Emotion-Guarded Branch Options)

这是一种固定的事件选项 Pattern，每个事件都遵循 3-option 范式：

| 位置 | 内容 | 特性 |
|------|------|------|
| **Option 1** | 正面反抗/超脱 | Requires: 高旷达 (一种特定情绪) |
| **Option 2** | 反面毁灭/功利 | Requires: 低旷达 (相反的特定情绪) |
| **Option 3** | 中庸/逃避 | 无条件可用，但产出平庸 |

### 4.2 情绪守卫的 Archetypes

三组核心情绪对立即心理原型表：

| ID | 情绪对 | 高旷达分支 (A) | 低旷达分支 (B) |
|----|--------|---------------|---------------|
| `pair_rebellion` | **反抗 vs 超脱** | 追求内心的安宁与自然的和谐 (TRANQUILITY) | 追求对外在压迫的反抗和破坏 (ARROGANCE) |
| `pair_despair` | **毁灭 vs 自毁** | 对社会不公的愤怒和对理想的坚守 (ANGER) | 对现状的绝望、消沉和自我放弃 (SORROW) |
| `pair_survival` | **功利 vs 麻木** | 对功名的渴望和对社会地位的追求 (AMBITION) | 对现实的疲惫、麻木和随波逐流 (FATIGUE) |

### 4.4 三大礼赋的时间锁 (State vs Time-Triggered)

| 方案 | 描述 | 结论 |
|------|------|------|
| **方案 A：严格历史时间锁** | Hardcoded Time-Trigger，特定年份自动触发 | 太死板，无法响应玩家行为 |
| **方案 B：状态与时代复合约束** | Date >= 749 && Date <= 753 && (State == '逢迎' \|\| '钻营') && Desperation > Threshold && 未站队 | **已选中** |

方案 B 通过状态约束确保事件只在合适的心理阶段触发，同时保留时间窗口的历史合理性。
