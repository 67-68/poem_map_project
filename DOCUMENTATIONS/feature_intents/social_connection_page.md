# SocialConnectionPage — 社交人脉总览页

## 设计意图

提供一个集中化的 NPC 关系总览面板，左侧树状图以地区/阵营维度浏览所有已知 NPC，右侧信息面板展示选中 NPC 的完整 NPCDocument 数据。

│  │                  │  ┌─ 基本信息 ──────────────┐  │ │

## 状态转换

```
页面初始化
  │
  ├─ 从 Database.npc_document 获取所有 NPCDocument
  ├─ 过滤 person_state != "uncharted"（玩家未知的 NPC 隐藏）
  │
  ├─ 默认模式 → "按地区分类"
  │    ├─ 读取每个 NPC 的 preferred_places
  │    ├─ 按地点分组构建 Tree（地点 → NPC 列表）
  │    └─ 未匹配的地点归入「其他地点」
  │
  ├─ 切换→ "按阵营分类"
  │    ├─ 查 RELATION_TARGET_TIER 获取阶层
  │    ├─ 按 T1/T2/T3 分组构建 Tree
  │    └─ 未在表中的归入「未知阵营」
  │
  └─ 点击 Tree 节点 → 右侧 Info Panel 刷新
       ├─ 基本信息: person_state(中文) / name / preferred_places(中文)
       ├─ 关系: leverage_keys / intro_keys
       ├─ 相关人物: relate_to
       ├─ 可用任务: 暂无数据
       └─ 资源转换配方: 暂无数据
```

## 数据来源

- NPC 数据：`Database.npc_document` / `Database.get_npc_document_all()`
- 关系状态：`NPCDocument.person_state` / `leverage_keys` / `intro_keys` / `help_count` / `relate_to`
- 阶层分级：`RelationFlagManager.RELATION_TARGET_TIER`
