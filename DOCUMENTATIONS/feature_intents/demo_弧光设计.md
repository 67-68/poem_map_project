## 弧光阶段总览

Demo 的 30 分钟被切分为四个阶段，对应杜甫从入仕幻想到安史之乱的精神崩塌过程。

---

### Phase 1: 撞墙期 (0-10 分钟)

> 野心系统设计：[听好了，你的野心系统不应该是一个正向的成长树，而应该是一个"倒置的榨汁机漏斗"](drafts://open?uuid=A1B59389-DF81-47D3-A944-86717E2005A9)

**时间顺序：** 745 年冬开始到 747 年春科举。

**玩家行为 + 体会 + 为什么他们会这么干：**

- **不断干谒** → 认为干谒是好的，未来可以成功
  - 在干谒事件中获取好处
  - 干谒按钮始终闪亮
  - 通过各种手法（开场提示等）把干谒塑造为主线，其他都为他服务。可使用野心面板提示干谒进度——"你希望把各方大佬都拜谒一遍，这样可以最大化科举成功率"
  - 在 UI 上画一个极其严肃、官方的【科举及格率】进度条
- **忽略坏处** → 认为"他们说的是假的"
  - 混杂在干谒事件后的朋友提醒（如郑虔和王维的提醒）：极其隐晦的、带血的台词来警告
  - 使用其他人（如李林甫门客）否定他们
- **走其他活动的线创作诗词**
  - 必须创作，否则没有东西可以干谒
  - 这一阶段的事件体现野心的特点（eg. 看到一段风景，想到这个可以写进诗词里）
  - 这一阶段的诗词给一个 `ambition` Tag，让他只可能出现那种干谒的诗词

> **注：** 为了兼顾反复的可游玩性，任何系统声明的正向投入都不应该没有产出。那种随机的小负面事件不算，在这个阶段干谒的结果会转化为正式版干谒成功线的朝堂文名。
>
> **注 2：** 使用机制设计而不是强制玩家去选择一条路线的方法是：给出对应的奖励。比如限制了仅走一条路线就要补充对应的多样性或者其他方面。

---

### Phase 2: 祛魅期 (10-15 分钟) — "逐渐不想做官" (The Turning Point)

**时间顺序：**
- 747 年春科举放榜后
- 事件跳转到秋天（呈现事件说明那种僵化）
- 跳转之后使用一个事件组成的场景来结束（漫步长安）

**玩家行为 + 体会 + 为什么他们会这么干：**

- **第一次呈现僵化的事件，后面继续点** → 想要知道后面是什么
  - 你感到茫然，不知道这意味着什么。继续拜谒
  - *第一次点击飘字：* "门卫看都没看你一眼。"
  - *第二次点击飘字：* "相国府的后门也对你关上了。"
  - *第三次点击飘字：* "你发现自己连打点下人的铜钱都没了..."
- **在事件场景中探索长安** → 想要知道各地有什么
  - 去富人家门口，富人嫌弃你（概率触发被富人的车轮泥水溅到和呵斥事件，以及被门卫嘲笑事件）
  - 去平民区，发现有很多穷人（事件：见鬼……我怎么没发现这里有这么多穷人？大概是因为在富人区核心吧）（概率触发：平民给你施舍钱，穷人靠近你问你是什么新来的穷人——因为没见过——下意识觉得脏想要退开，发现自己也是脏的）
  - 有所触动之后去市场，发现买不起东西
  - 发现郑虔，观察（因为发现他也很穷，在之前遇上的时候看他衣服干净，有补丁以为只是作秀），逐渐被感动，然后被叫过去一起 hang out（有一个情感的转移，不是直接僵化到洒脱）
- **午夜分别郑虔，那个决定进展的事件**
  - 放弃拜谒
  - 继续拜谒（现在未解锁）

### Phase 3: 陋室期 (15-25 分钟) — "贫穷但快乐"

> 详细设计请参见 [陋室阶段-旷达系统](DOCUMENTATIONS/feature_intents/陋室阶段-旷达系统/) 文档集。

**时间顺序：**
- 747 年科举之后
- 747 之后给一段时间让玩家享乐
- 748 年跳转到 751 年
- 直到 752 年高适离开（旷达到底是真正的超脱，还是对现实无能为力的逃避）
- 752 后半年跳转到 755 年

**玩家行为 + 体会 + 为什么他们会这么干：**

- **游山玩水 + 参加清流的宴会**
  - 构成一个完整的循环，使用意象获取文名
  - 文名再给出 Trait，导致其他地方人尊敬，比如市场 discount
  - 可以蹭王维的饭，不然钱不够，越高等级越能蹭饭和被接济（但只是饿不死）
  - 建立和其他人的情感链接
  - （隐藏：后面可以用好感度让他们推荐你，李林甫死了，获得官场名声）
- **求官**
  - 高适走了，导致野心再次出现
  - 主线：准备三大礼赋（获得极高的名声，但 `MONEY` 收益为 **0**）
- 然后直接跳转到 755

**核心设计问题：** 这个阶段的体验由旷达系统驱动。需要建构什么事件库——由旷达的转折和弧光决定（比如一开始不旷达→然后旷达→高适走了之后再次不旷达）。

可以让旷达值到达 0 来做继续拜谒的事件，而不是在之前的事件中二选一。

旷达弧光结构：
```
0: 不是很旷达，想要入世，继续拜谒
→ 30: 有点旷达，看见贵人还是会尊敬
→ 70: 非常旷达，视官员为普通人
→ 100: 旷达到了极致，准备归隐田园
```

每个阶段都有不同的 EventBase，玩家需要 manage 它。上升或下降的 Trade-off 是核心设计。

### Phase 4: 毁灭与旁观者 (25-30 分钟) — "安史之乱爆发"

**时间顺序：**
- 755 年获得小官
- 紧接着，回家乡见老婆孩子（使用事件场景呈现村口）
- 在见到死亡的那一刻，强制触发安史之乱事件

**玩家行为 + 体会 + 为什么他们会这么干：**

- **接受小官**
  - **华丽反转：** 当时间跳跃结束，UI 突然播放极度华丽的"圣旨/报喜"动效（最浮夸的 Level 3 UI 特效，金光闪闪）。大标题写着：**【吏部告身：授官！】**
  - **残酷反转：** 玩家满怀期待地点开，里面的文本却极度干瘪：
    > _"右卫率府兵曹参军。从八品下。掌管东宫兵器库。俸禄：勉强够买几斗生麦。"_
- **强制事件：回家探亲**
  - 在路上，使用流民暗示情况不好
  - 呈现各地的庄稼歉收
  - 呈现京城内和京城外的区别，光顾着开心了都没注意到
  - **交互压缩：** 直接在大地图上把所有节点锁死，只留下一个闪烁的地点：**【奉先县】**。
  - **点击扣除：** 玩家每点一次【赶路】，屏幕变暗一分，BGM 里的风声变大，飘出一行字幕（流民、饿殍、冻死骨）。点三次，直接切入核心场景——"找不到家的村落"。
- **回家探亲：所在的小村作为事件场景**
  - 从外面一路往里走，没看见人
  - 在这里反复在两个事件之间插入一个不详的想法，心悸，死亡的感觉，每次的文案不同，但都能让人想起死亡
  - 脚步变得沉重，微弱的哭声，回光返照的哭声，然后接近没有
  - 在这一期间，杜甫都在村子里迷路，因为他太不常回来了，找不到妻子儿女的新家（他们因为贫困搬迁到了更坏的房子，没跟杜甫说）
  - 也就是说，像是杜甫不常回来这个事实，导致他错过了跟孩子的最后一面和救他的机会（实际上看见了也会死，因为吃的没有那么快？）作为 Trade-off
  - 具体的 UI 参考（待定）

## 全局设计原则

- 每个 Phase 之间的状态转变通过事件驱动，而非硬编码时间锁
- 玩家的历史行为会积累隐式 Trait，影响后续事件的触发条件和文本
- 如果某个系统实现不了就硬编码兜底
